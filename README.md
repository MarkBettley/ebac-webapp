# Java Web Application

Aplicación web desarrollada durante la formación Backend Java de EBAC.

## Descripción

Proyecto académico orientado a la construcción de aplicaciones web con Java y a la integración de los conceptos estudiados durante la formación backend.

## Tecnologías

- Java
- Maven
- Desarrollo Web
- H2

## Uso

Clona el repositorio y abre el proyecto en un entorno compatible con Java y Maven.

Las dependencias y configuración del proyecto se encuentran definidas en `pom.xml`.
